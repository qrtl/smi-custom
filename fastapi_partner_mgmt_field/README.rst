This module extends the partner schema for fastapi_partner_mgmt to use.

This module doesn't depend on anything, and fastapi_partner_mgmt depnds
on this module. When the content of EXTRA_PARTNER_FIELDS is changed,
fastapi_partner_mgmt needs to be upgraded.
